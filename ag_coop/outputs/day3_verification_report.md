## 坐标系约定

### 内部坐标系
```
(i, j) = (row, col)
- i: 行索引，0 = 底部，9 = 顶部
- j: 列索引，0 = 左侧，9 = 右侧
```

### 可视化约定
```
matplotlib: origin='lower'
- i=0 在图像底部
- j=0 在图像左侧
- scatter(j, i) = scatter(x, y)
```

如果位置相反，则需要 y-flip。

## 坐标转换验证

### Cell → World 转换
```python
x = origin[0] + (j + 0.5) * resolution
y = origin[1] + (i + 0.5) * resolution
```

示例：
- Cell (1, 1) → World (0.30, 0.30) ✅
- Cell (8, 8) → World (1.70, 1.70) ✅

### World → Cell 转换
```python
j = floor((x - origin[0]) / resolution)
i = floor((y - origin[1]) / resolution)
```
